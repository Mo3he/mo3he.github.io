Independent project guide / Axis cameras

What can your camera do?

I build apps that run on Axis cameras. Pick what you want to do below. Each link opens the project page, or its installation instructions on GitHub.

Remote accessVideoAutomationTelemetry
01 / Remote access

Reach a camera remotely

Start with the network you already use. For WireGuard, the choice depends on which end accepts the connection.

  • Join an existing network: use Tailscale for a tailnet, NetBird for a NetBird network, or ZeroTier for a ZeroTier network.
  • Run your own WireGuard: choose the WireGuard client if the camera connects to your server. Choose WireGuard Server if peers connect to the camera as their gateway.
  • Connect to a VPN gateway: use OpenVPN for an OpenVPN endpoint or OpenConnect for GlobalProtect / Prisma Access.
  • Need a one-off tunnel? Tailcat gives you ad-hoc access without joining a tailnet.
02 / Video

Watch live or take recordings with you

  • Live video: use MediaMTX to serve streams over RTSP, HLS, or WebRTC. If your Home Assistant setup already uses go2rtc, run go2rtc on the camera.
  • Already recorded? Use Recording Export to review SD card footage and download clips in bulk from your browser.
03 / Automation

Make something happen when an event fires

  • Run a rule on the camera: use Event Engine to combine triggers and conditions, then send a webhook or MQTT message.
  • Integrate with an existing system: expose camera events to a building controller with BACnet/IP, or connect cameras and sensors to a SCADA host with MQTT Sparkplug B.
04 / Telemetry

See how a device is doing

  • Check it now: open a live dashboard with Camera Metrics. It also exports readings to Prometheus or MQTT.
  • Keep a history: use the InfluxDB collector to send device and sensor readings to InfluxDB v2.
