Camera Metrics

See how the device is doing now and check its temperature, storage and CPU history. Everything runs on the camera itself, so there is no server to set up.

  • Live charts for CPU, memory, temperature, storage, network and power
  • History from 5 minutes to 30 days that survives a reboot
  • Alerts, plus export to Prometheus, MQTT and Home Assistant, or InfluxDB
