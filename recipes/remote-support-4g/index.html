Recipe

Remote camera access, without port forwarding

Open a temporary, encrypted connection to a camera behind 4G or another restrictive network. No inbound ports or permanent VPN required.

The situation

Cameras on construction sites, in vehicles or at remote cabinets often sit behind a 4G router. The mobile network blocks incoming connections, so port forwarding is impossible, and setting up a VPN for one support call is too much work. Tailcat opens a short-lived tunnel that works from behind NAT, with no account.

What you need

  • An Axis camera on AXIS OS 12.10 or later (Tailcat is tested on aarch64 devices)
  • Someone on site who can install an app on the camera
  • The tailcat command-line tool on the remote expert's computer

Steps

  1. On site: download the latest .eap from the Tailcat releases and install it on the camera under Apps.
  2. Open the app, press Start and copy the tailcat address. Send it to the remote expert over a channel you trust.
  3. Remote expert: install the tool (brew install tailcat on macOS) and check the camera is reachable:
    tailcat ping <address>
  4. Open the camera's web interface through the tunnel:
    tailcat browse <address>
  5. When the job is done, press Stop in the app. The address stops working immediately.

Good to know

  • The address works like a password: anyone who has it can reach the forwarded ports while the tunnel runs.
  • Turn on Auto-stop so a forgotten tunnel closes itself, and use Allowed client keys if you keep the same address.
  • If a direct path is not possible, traffic goes through a relay, which is rate limited. Settings work fine; live video may be slow.
  • Need access every day rather than for one job? Use Tailscale (or another VPN app) for a permanent connection instead.
